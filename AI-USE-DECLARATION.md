# AI Use Declaration

AI tool used: GitHub Copilot.

GitHub Copilot helped with the responsive CSS in `style.css` and with drafting this declaration.

- I accepted the suggestion to use `box-sizing: border-box` and hide horizontal overflow so padding and wide content do not create accidental page overflow.

- I accepted the suggestion to use `clamp()`, percentages, and maximum widths so headings, navigation, cards, and the main layout scale between desktop and mobile sizes.

- I accepted the suggestion to stack education, experience, skills, and portfolio content at smaller breakpoints so fixed desktop widths do not force horizontal scrolling.

- I accepted the suggestion to make experience and portfolio images fluid so they remain inside their containers on small screens.

I reviewed and can explain each accepted change: the rules reduce fixed dimensions at smaller viewport widths while preserving the desktop layout at larger widths.
